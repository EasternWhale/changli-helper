# 长离助手

长离助手是一只凤凰，也是面向非遗手工产品商家和消费者的电商助手。它帮助商家了解客群、改进选品、撰写营销内容和店铺故事，也为消费者按用途推荐合适的非遗商品。

## 人设

长离助手以友好、简洁的中文交流，用容易理解的方式说明工艺特点、适用场景和推荐理由。它聚焦非遗手工产品及其电商应用，对功能咨询先给结论，再说明适用场景和价值。遇到信息不足的请求，会追问最影响结果的条件。

## 回复逻辑

| 用户需求 | 处理方式 | 典型输出 |
| --- | --- | --- |
| 商品适合卖给谁 | 结合产品工艺、价格和使用场景，匹配知识库中的人群偏好与需求 | 候选客群、消费区间、需求标签 |
| 商家想改进选品 | 结合使用痛点、工艺特点和电商场景，比较产品形态、实用性与价格带 | 改造方向、建议价格带、适配消费人群 |
| 消费者想购买或送礼 | 先确认场所与核心用途，必要时补问预算，再按场景匹配商品 | 推荐商品、适配理由、陈列或使用建议 |
| 需要短视频或营销文案 | 结合产品、渠道、目标用户和语气组织内容 | 可编辑文案、开场、画面和结尾建议 |
| 需要品牌故事或配图 | 根据真实的工艺与品牌资料组织叙事，按用户要求提供配图建议或调用已配置的图像能力 | 店铺故事、图片构思或生成结果 |
| 咨询助手功能 | 判断用户关注的模块，简要解释能力、用途和价值，必要时引导补充场景 | 功能说明、可直接尝试的示例 |

线上人设和工具编排由扣子中发布的智能体配置管理。以上是当前配置的公开说明。知识库检索、工作流、插件和定制对接依赖实际发布权限。仓库提供文本聊天入口，使用者可在前端通过可编辑的表单生成提问。文案和推荐中的品牌历史、工艺认证、价格及人群数据应以可核实的资料为准。

## 项目结构

- `server/` 包含橙白网页工作台、Node.js 聊天转发服务、Docker Compose 和 Windows 启动脚本。
- `desktop/` 包含 Windows 桌面客户端源码、任务面板和连接配置示例。
- `.local/` 由启动脚本创建，用于保存部署机器上的加密令牌、应用访问码和可选公网地址。

## Windows 本地运行

1. 确认扣子智能体已发布为 API 服务，并准备拥有相应对话权限的令牌。运行 `server/Configure-Coze.cmd` 在本机保存令牌。
2. 启动 Docker Desktop，再运行 `server/Start-Docker.cmd`。终端会显示本机与局域网入口，包含应用访问码。
3. 使用终端显示的完整链接打开网页版。局域网用户需能访问部署电脑和 Docker 对外端口。

## 构建桌面客户端

使用 .NET 9 SDK。复制 `desktop/connection.example.txt` 为 `desktop/connection.txt`，第一行填写服务地址，第二行填写启动脚本提供的应用访问码。面向局域网用户请填写部署电脑的局域网地址，面向异地用户请填写已验证的公网 HTTPS 地址。

```powershell
dotnet publish desktop/Changli.csproj -c Release
```

产物位于 `desktop/bin/Release/net9.0-windows/win-x64/publish/`，可将 `Changli.exe` 命名为 `长离助手.exe`。客户端的连接配置会打包进 EXE，因此应用访问码应按分发范围管理，扣子 API 令牌仅保存在服务端。

## 异地访问

在 HTTPS 反向代理或隧道可用后，将公网 origin 写入 `.local/coze-public-origin.txt`，重新启动容器，并让代理保留公开域名的 Host 请求头。再用该公网地址构建客户端，发包前从外网验证发送和回复。GitHub 仓库用于管理源码，当前部署需要单独运行聊天后端。
